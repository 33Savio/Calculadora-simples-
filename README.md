# Calculadora-simples-em-Python
Projeto desenvolvido em Python para realizar cálculos matemáticos diretamente através de expressões digitadas pelo usuário, como 2+2, 10*5 e (20+10)/2.
Tecnologia utilizada: Python
Funcionalidades:
Operações de adição, subtração, multiplicação e divisão
Expressões matemáticas
Tratamento de entradas inválidas
Encerramento pelo comando sair
